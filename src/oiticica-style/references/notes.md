# Notes for oiticica-style

## Source Basis

Oiticica names six essential qualities and six corresponding defects in §5 of the first part of *Manual de Estilo*. In §25, he says it is easier and more pedagogical to avoid defects before acquiring the qualities jointly. This supports a defect-first aggregate pipeline; it does not support six independent defect topics.

## Eval Polarity

The positive pipeline cases contain an evidenced defect or failed quality for the router to repair or carry through both stages. The negative preservation case contains no target defect and requires the router to preserve a strong passage. The strong description case tests genre routing and complete aggregate coverage without requiring the model to invent a fault. The narrow case tests that an explicit skill request suppresses the general pipeline.

## Source Boundary

Every eval passage is an exact quotation or verbatim excerpt from a public-domain, widely read English work or civic or sacred text. No eval fixture is invented or a source-model paraphrase.
